# 字体目录

把 `.ttf` / `.otf` / `.ttc` 文件放到这里，插件会优先使用。

如果留空，插件首次使用时会从 GitHub 自动下载 **思源黑体 CN Regular** (~11MB) 到本目录。

推荐字体（手动下载后放到此目录即可）：

- **LXGW WenKai Lite**（~4MB，手写楷书风）
  <https://github.com/lxgw/LxgwWenKai-Lite/releases>
- **Smiley Sans 得意黑**（~3MB，现代显示体）
  <https://github.com/atelier-anchor/smiley-sans/releases>
- **阿里巴巴普惠体 3.0**（~6MB，通用无衬线）
  <https://fonts.alibabagroup.com/>
